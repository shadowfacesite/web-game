# ЗАТОН

Веб-хоррор от первого лица. Этап Э0 — каркас: пустая сцена, эталоны
масштаба, ходьба и захват мыши.

## Смотреть

Игра публикуется на GitHub Pages при каждом изменении в ветке `main`.
Адрес — `Settings` → `Pages`, вида `https://<логин>.github.io/zaton/`.

## Управление

| | |
|---|---|
| щелчок по экрану | захватить мышь |
| WASD | идти |
| Shift | бежать |
| Esc | отпустить мышь |
| **F9** | отчёт о железе в буфер обмена |

Отчёт по F9 нужен для отладки картинки: в нём видеокарта, максимальная
анизотропия, размер текстур, цветовое пространство и точность шейдера —
то, чего не видно на скриншоте.

## Разработка на своей машине

```
npm install
npm run dev
```

Откроется `http://localhost:5173/`, правки подхватываются на лету.
Сборка — `npm run build`, проверка типов — `npm run typecheck`.

## Чертёж

Открывается по адресу игры с хвостом `/plan.html`. Ползунок сверху
переключает стадию: двери меняют цвет, подсвечивается активный уровень.

Чертёж **не хранится в репозитории**. Он собирается из `spec/house-map.json`
при каждой публикации. Править его напрямую бессмысленно — правится карта.

## Планировка

`spec/house-map.json` — единственный источник правды о доме. Из него растут
геометрия, коллизии, валидатор и чертёж. Второй копии планировки в проекте
быть не должно: прошлый заход умер именно от неё.

```
npm run validate    проверить карту
npm run map 7       карта проходимости текстом, на указанной стадии
npm run plan        перерисовать чертёж
```

Проверка запускается сама перед каждой сборкой. Сломанная карта валит
сборку и в игру не попадает.

## Устройство

| путь | что там |
|---|---|
| `src/main.ts` | точка входа и игровой цикл |
| `src/render/scene.ts` | сцена, камера, рендерер, все параметры картинки |
| `src/game/player.ts` | мышь, ходьба, бег |
| `src/debug/hud.ts` | строка FPS в углу |
| `src/debug/report.ts` | отчёт по F9 |
| `src/world/map.ts` | типизированный доступ к планировке |
| `spec/house-map.json` | планировка — единственный источник правды |
| `tools/validate.mjs` | проверка карты и маршрута без браузера |
| `tools/plan.mjs` | сборка чертежа из карты |
