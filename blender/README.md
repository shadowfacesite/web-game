# Работа в Blender

## Порядок

1. `npm run blender` в проекте — появится `export/house.obj` и `export/kit.obj`.
2. В Blender: `Edit → Preferences → Add-ons → Install…` → выбрать
   `blender/zaton_kit.py` → включить галку.
3. `3D-вид → N → вкладка «Затон»`.
4. Указать папку проекта, нажать **Настроить сцену**.
5. **Подложка: дом** — блокаут ляжет каркасом, выделить его мышью нельзя.
6. Моделировать поверх, складывая всё в коллекцию `карта`.
7. **Проверить карту** → **Выгрузить .glb**.
8. Файл окажется в `public/models/house.glb`. Перетащить его на окно
   редактора — или он подхватится сам кнопкой «Карта .glb».

Стартового `.blend` в комплекте нет намеренно: он бинарный, я не могу его
ни собрать, ни проверить. Скрипт делает то же самое за десять секунд и,
в отличие от файла, не устареет после первой правки соглашений.

## Оси

Blender внутри Z вверх, glTF и кит — Y вверх. Экспортёр с галкой **+Y Up**
переводит так:

| В Blender | Станет в игре | Что это |
|-----------|---------------|---------|
| X | X | длина предмета |
| Z | Y (вверх) | высота |
| Y | −Z | глубина |

Отсюда три правила:

- **напольный** предмет — низ на `Z = 0`, начало координат в центре пятна;
- **настенный** — плоскость стены `Y = 0`, предмет растёт в `+Y`;
- **длина** — всегда вдоль `X`.

Кнопка «Поставить начало координат» делает это сама: выбери режим и нажми.

Галку **+Y Up** при экспорте не снимай. Настройки импорта `.obj` не трогай —
у них значения по умолчанию как раз нужные.

## Коллекции

| Имя | Что кладут | Идёт в игру |
|-----|-----------|-------------|
| `карта` | геометрия уровней | да |
| `карта / уровень_cellar…f3` | по этажам, чтобы прятать по одному | да |
| `коллизии` | простые коробки, во что упирается игрок | отдельно |
| `подложка` | блокаут из `export/*.obj` | нет |
| `черновик` | всё, что пока непонятно куда | нет |

Экспорт берёт только `карта`. Меш, лежащий вне коллекций, в файл не попадёт —
проверка про такие говорит отдельно.

## Что ломается чаще всего

| Симптом в игре | Причина | Лечение |
|----------------|---------|---------|
| модель размером с ноготь | не применён масштаб | `Ctrl+A → Scale` |
| дом лежит на боку | снята галка `+Y Up` | вернуть при экспорте |
| предмет встаёт не туда, куда кладёшь | начало координат в стороне | «Поставить начало координат» |
| предмет серый | нет материала | назначить любой |
| часть модели пропала | меш лежал вне коллекции `карта` | перенести |

Всё это ловит **Проверить карту** до выгрузки, и оно же ловится второй раз
на стороне сайта при загрузке `.glb` — сообщение появится внизу экрана.

## Одна планировка

`spec/house-map.json` — единственный источник правды о планировке. Из него
растут дом, коллизии, чертёж и валидатор. `export/house.obj` — его отпечаток:
поменял карту → `npm run blender` → подложка обновилась.

Пока стены живут в карте, а Blender даёт мебель, реквизит и отделку —
всё сходится само. Как только стены поедут в Blender, планировок станет две,
и понадобится своя коллекция `коллизии` плюс проверка проходимости по ней.
Это делается, но это отдельная работа, и начинать её стоит на проверенном
конвейере, а не сразу.
